# Attendance Management System Using QR Code

Mini Project | BSc Information Technology
Thakur College of Science & Commerce, Mumbai (2025-2026)

## About
A web-based system where teachers generate a QR code 
and students scan it to mark attendance automatically 
with date and time.

## Features
- Teacher panel to generate unique QR codes
- Students scan QR to mark attendance instantly
- Prevents duplicate attendance entries
- Auto stores date and time in database
- Simple and mobile-friendly interface

## Tech Stack
- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Server: XAMPP
- Tools: VS Code

## How It Works
1. Teacher opens system and generates QR code
2. QR contains a unique time-based token URL
3. Student scans QR and submits roll number
4. System checks for duplicates then saves attendance
5. Records stored with date and time in MySQL
